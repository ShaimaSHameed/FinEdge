A full-stack AI-powered stock analysis platform built over two semesters at AUS. 4-person team. I was the Project Manager and Fundamental Analysis Lead.

The platform runs three independent ML models and fuses them into a single weighted Buy, Sell, or Hold recommendation across 237 US large-cap stocks.

---

## Results

| Model | Details | Result |
|-------|---------|--------|
| Fundamental | IC Score · AUC · Hit rate | 0.1477 · 0.5817 · 56.5% across 9,026 predictions |
| Fundamental | Market outperformance | Strong Buy picks +12 percentage points |
| Technical | MSFT forecast · MAE | $414 to $418 · 0.479 |
| Sentiment | Return vs buy-and-hold | +178% vs 130% benchmark |
| Fusion | Combined Sharpe ratio | 3.69 |
