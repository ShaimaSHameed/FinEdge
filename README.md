# FinEdge
**Senior Design Project · 2025-2026**

A full-stack AI-powered stock analysis platform built over two semesters. 4-person team.

The platform runs three independent ML models, Fundamental, Technical, and Sentiment, fused into a single weighted Buy, Sell, or Hold recommendation across 237 US large-cap stocks.


## Results

| Model | Metric | Result |
|-------|--------|--------|
| Fundamental | Market outperformance | +12pp on Strong Buy picks |
| Technical | MSFT forecast | $414 to $418 |
| Sentiment | Return vs benchmark | +178% vs 130% buy and hold |
| Fusion | Sharpe ratio | 3.69 |

## Stack

Python · FastAPI · Next.js 14 · PostgreSQL · Docker · LightGBM · Optuna · TradingView · Alpaca API
